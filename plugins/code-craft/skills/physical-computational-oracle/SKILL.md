# Машинный оракул вычислительной физики и газодинамики (Physical Oracle)

В вычислительной физике и газодинамике стандартные программные тесты («проверить возвращаемое значение функции») бессмысленны: код может идеально компилироваться и проходить тесты, но выдавать физически неверное или неустойчивое решение.

Навык предоставляет методику создания **физических проверочных оракулов**, гарантирующих достоверность расчетного ядра.

---

## 1. Контрольный перечень физических инвариантов

Перед признанием любой модификации численного решателя успешной агент обязан проверить:

| Физический критерий | Математическое условие | Что означает нарушение |
|---|---|---|
| **Сохранение массы** | $\sum_{\text{ячейки}} \rho_i^{n+1} V_i = \sum_{\text{ячейки}} \rho_i^n V_i + \Delta t \oint (\rho \vec{u}) \cdot d\vec{S}$ | Неконсервативная разностная схема, утечка массы на границах. |
| **Неотрицательность давления** | $p_i > 0 \quad \forall i$ | Срыв расчета при ударных волнах, локальный вакуум из-за неверного потока. |
| **Неотрицательность плотности** | $\rho_i > 0 \quad \forall i$ | Развал газодинамического состояния уравнения Клапейрона-Менделеева. |
| **Число Куранта (CFL)** | $CFL = \max \left( \frac{(|u| + c)\Delta t}{\Delta x} \right) \le CFL_{\max}$ | Численная неустойчивость, взрыв схемы по времени. |
| **Энтропийное условие** | $\Delta S \ge 0$ на скачках уплотнения | Появление нефизических волн разрежения с разрывом (ударных волн разрежения). |

---

## 2. Канонические верификационные тесты (Benchmarks)

Для верификации газодинамических схем (Godunov, Roe, HLLC, WENO) используются строгие эталонные задачи с аналитическим решением:

1. **Задача о распаде разрыва Сода (Sod Shock Tube):**
   * Область $x \in [0, 1]$, разрыв при $x=0.5$.
   * Слева: $\rho_L = 1.0, p_L = 1.0, u_L = 0$.
   * Справа: $\rho_R = 0.125, p_R = 0.1, u_R = 0$.
   * *Критерий:* Точное воспроизведение положения контактного разрыва и ударной волны без нефизического дребезга (TVD-свойство).
2. **Задача Шу-Ошера (Shu-Osher Shock-Acoustic Interaction):**
   * Взаимодействие ударной волны $M=3$ с периодическим акустическим возмущением плотности.
   * *Критерий:* Проверка способности схемы передавать высокочастотные колебания без замазывания численной вязкостью.

---

## 3. Оценка сеточной сходимости: Индекс GCI (Grid Convergence Index)

Для доказательства независимости решения от сетки:
1. Выполняется расчет на трех последовательно сгущающихся сетках с коэффициентом $r = h_2 / h_1 = 2$.
2. Вычисляется эффективный порядок сходимости схемы $p$:
   $$p = \frac{\ln\left(\frac{f_3 - f_2}{f_2 - f_1}\right)}{\ln(r)}$$
3. Рассчитывается экстраполяция Ричардсона $f_{\text{exact}}$ и сеточная неопределенность $GCI$.
4. Если эффективный порядок $p$ совпадает с теоретическим порядком аппроксимации схемы (например, 2 для MUSCL или 5 для WENO) — решатель математически корректен.
