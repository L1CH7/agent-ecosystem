# Организация исследовательского пространства и матрица литературы (Beeblio Standard)

Навык регламентирует файловую структуру научного проекта и ведение матрицы литературного обзора для исключения хаоса в данных, расчетах и библиографии.

---

## 1. Каноническая файловая структура проекта

Любой исследовательский проект или папка статьи организуется по 4-уровневой схеме:

```text
исследовательский_проект/
├── 1-References/              # Научные источники и библиография
│   ├── references.bib         # Единый файл BibTeX со всеми ключами цитирования
│   └── papers/                # Исходные PDF-файлы статей и монографий
├── 2-Data/                    # Первичные расчетные и экспериментальные данные
│   ├── meshes/                # Сетки (ICEM, Gmsh, OpenFOAM, ANSYS)
│   ├── raw/                   # Сырые дампы вычислений, замеры датчиков
│   └── geometry/              # Исходные CAD/STEP модели
├── 3-Analysis/                # Математическая обработка и сопоставление
│   ├── literature-matrix.md   # Матрица обзора существующих решений и аналогов
│   ├── scripts/               # Скрипты обработки результатов (Python, NumPy, PyVista)
│   └── postprocessed/         # Сводные таблицы и профили параметров
└── 4-Reports/                 # Готовые публикации и отчетные материалы
    ├── figures/               # Векторные графики (SVG, PDF) высокого разрешения
    ├── main.tex               # Исходный код статьи в LaTeX (или draft.md / draft.docx)
    └── main.pdf               # Скомпилированный документ по ГОСТ / шаблону журнала
```

## 2. Матрица литературного обзора (`literature-matrix.md`)

Перед написанием аналитического обзора или раздела «Введение» составляется матрица литературы в `3-Analysis/literature-matrix.md`. Это исключает бессистемное цитирование.

### Шаблон таблицы матрицы:

| Ключ BibTeX | Авторы, Год | Физическая постановка / Среда | Численный метод / Модель турбулентности | Параметры сетки / Верификация | Ключевой результат | Недостатки / Пробел для нашей работы |
|---|---|---|---|---|---|---|
| `ivanov2024cfd` | Иванов и др., 2024 | Сверхзвуковое течение идеального газа, $M=2.5$ | WENO5 + RANS ($k-\omega$ SST) | $1.2 \cdot 10^6$ ячеек, труба Сода | Погрешность по давлению $\le 3\%$ | Изотермическая стенка, нет учета химических реакций |
| `smith2023plasma` | Smith et al., 2023 | Неравновесная плазма в сопле | Двухтемпературная МГД | Сетка $500\text{k}$, валидация по NASA TM | Выявлен отрыв потока при $B > 1.2\text{ Тл}$ | Двумерное приближение, отсутствует пространственная трехмерность |

## 3. Правила ведения библиографии `references.bib`

1. **Единый стандарт ключа цитирования:**  
   `[первый_автор_латиницей][год_публикации][первое_слово_заголовка]`  
   Пример: `@article{ivanov2024shock, ...}`
2. **Обязательные поля для каждой записи:**
   * `author`, `title`, `journal` (или `booktitle`), `year`, `volume`, `number`, `pages`, `doi`.
3. **Защита от невалидных записей:**
   * Каждая запись должна проверяться на валидность синтаксиса BibTeX;
   * Наличие поля `doi` строго обязательно для современных статей (начиная с 2000 года).
