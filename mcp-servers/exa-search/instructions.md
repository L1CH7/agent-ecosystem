# Exa Search Grounding — Инструкция и регламент для AI-агентов

## 1. Архитектура и назначение
Сервер `exa-search` предоставляет сверхбыстрый семантический веб-поиск и извлечение очищенного контента в формате Markdown на базе официального SDK `exa-py` (v1.8+):
- **Скорость:** 0.5–2 секунды на сетевой запрос;
- **Семантическое понимание:** понимает сложные, развернутые гипотезы и технические описания без необходимости подбирать ключевые слова;
- **Чистый Markdown:** автоматически удаляет мусорный HTML, скрипты, навигацию и баннеры согласия;
- **Локальная библиотека знаний (Knowledge Library FTS5):** все найденные статьи и выжимки автоматически сохраняются в локальное хранилище для мгновенного повторного поиска за 0.5 мс без выхода в сеть и без затрат баланса.

---

## 2. Доступные инструменты платформы Exa

### Сетевые инструменты поиска (Exa API)
1. **`exa_search(query, project='default', num_results=5, search_type='auto', category=None, include_domains=None, exclude_domains=None, highlights=True)`**  
   Основной семантический поиск. Все найденные результаты автоматически индексируются в локальную библиотеку под указанным проектом.
2. **`exa_answer(query)`**  
   Мгновенный прямой синтез ответа на вопрос с проверяемыми ссылками-первоисточниками за 1–2 секунды.
3. **`exa_search_batch(queries, project='default', num_results=3, highlights=True)`**  
   Параллельный пакетный запуск массива запросов через `asyncio.gather` за 1–3 секунды.
4. **`exa_find_similar(url, project='default', num_results=5, highlights=True)`**  
   Поиск веб-страниц и статей, семантически похожих на переданный URL (поиск прямых аналогов или похожих библиотек).
5. **`exa_get_contents(urls, project='default', text_max_characters=4000)`**  
   Пакетное скачивание чистого текста страниц по готовым ссылкам (с исполнением JS и разбором PDF). Тексты сохраняются в библиотеку подпроекта.
6. **`exa_deep_research(instructions)`**  
   Автономный многошаговый исследовательский агент Exa (Deep Research Engine).

### Инструменты локальной библиотеки (Zero-Cost / 0.5 мс)
7. **`exa_library_search(query, project=None, limit=5)`**  
   **Мгновенный локальный полнотекстовый поиск (SQLite FTS5 / BM25)** по всей накопленной базе найденных документов, статей, формул и выжимок с возможностью фильтрации по подпроекту (`project="gzla-cfd"`). Работает без сети и с нулевой стоимостью ($0.00).  
   *Рекомендуется использовать перед выходом в сеть, если по теме уже проводились поиски.*
8. **`exa_library_status()`**  
   Показывает количество сохраненных документов, число активных проектов и путь к базе.
9. **`exa_library_clear()`**  
   Полный сброс локальной библиотеки (очистка базы).

### Управление пулом ключей и биллинг
10. **`exa_pool_status()`**  
    Аудит пула ключей: количество активных/исчерпанных счетов, суммарный расход в долларах и число выполненных запросов.
11. **`exa_add_key(api_key)`**  
    Добавление нового API-ключа в пул keys.txt без ручного редактирования файлов.

## 3. Лимиты и оптимальные параметры Exa API (Практические нормы)
Экспериментально подтверждено на производственном аккаунте:
- **Лимит результатов (`num_results`):**
  - До 10 результатов: $0.007 (базовая ставка).
  - 25 результатов: $0.022.
  - До 100 результатов: $0.095 (максимум за один вызов API — возвращает до 100 полных документов).
- **Лимит объема текста (`max_characters`):**
  - Текст страницы до **50 000 символов** возвращается без наценки (та же базовая ставка $0.007).
- **Рекомендация для агентов по объему контекста:**
  - Для быстрой разведки и поиска ссылок: достаточно базового `num_results=5..10` со сниппетами и цитатами (`highlights=True`).
  - Для скачивания полных научных статей, документации и отчетов: используйте `exa_get_contents` с `text_max_characters=15000..40000`.

## 4. Балансировка ключей и отказоустойчивость (Multi-Key Balancer)
- **Файл ключей:** `/home/vaivanov/.gemini/mcp-servers/exa-search/keys.txt` (по одному ключу на строку).
- **Файл статусов:** `/home/vaivanov/.gemini/mcp-servers/exa-search/key_status.json` (ведется сервером автоматически).
- **Автопереключение:** Если на ключе заканчиваются средства (HTTP 402/403), сервер изолирует его как `exhausted` и мгновенно повторяет запрос со следующим активным ключом.
- **Оповещение:** При исчерпании всех счетов возвращается четкое уведомление о необходимости пополнить пул.
